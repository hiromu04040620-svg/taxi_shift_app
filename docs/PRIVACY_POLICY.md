# プライバシーポリシー

制定日: 2026年6月13日
最終更新日: 2026年7月15日

TaxiShift（以下「本アプリ」）は、タクシー乗務員向けにシフト、勤務実績、売上を端末内で管理するためのアプリです。

## 取得する情報

本アプリは、ユーザーが入力した以下の情報を端末内に保存します。

- シフト設定、シフト変更内容
- 勤務開始・終了時刻、休憩時間、勤務メモ
- 売上、走行距離、乗車回数、売上メモ
- アプリ設定

これらの情報は、アプリの機能提供のために利用され、開発者のサーバーへ送信されません。広告SDKへも送信されません。

Google Mobile Ads SDK（AdMob）は、広告配信、広告効果の測定、サービス改善および不正防止のため、次の情報を取り扱う場合があります。

- IPアドレス（端末のおおよその地域の推定に使用される場合があります）
- 端末識別子（広告識別子およびアプリ・開発者単位の識別子を含みます）
- 表示された広告などの広告データ
- アプリ起動や広告操作などの製品操作情報
- クラッシュ情報、パフォーマンス情報およびその他の診断情報

実際に取り扱われる情報は、端末の設定、地域、同意内容、広告の配信方式などによって異なります。

## 広告配信

無料利用時は、カレンダー画面とサマリー画面にGoogle AdMobのバナー広告を表示します。広告はGoogleおよび広告配信に関わる事業者から配信されます。

アプリ内課金「広告非表示」を購入すると、これらの広告は表示されません。購入の有無にかかわらず、シフト、勤務、売上管理などの主要機能を利用できます。

## トラッキング許可

本アプリは、広告の関連性向上と広告効果の測定を目的として、iOSのApp Tracking Transparency（ATT）による許可を求める場合があります。許可した場合、Google Mobile Ads SDKが端末の広告識別子を広告配信および測定に使用する場合があります。

許可しない場合でもアプリの全機能を利用でき、広告識別子を使用しない広告が表示される場合があります。広告に関する同意は、対象地域ではアプリの「設定」から確認・変更できます。

本アプリは、Google User Messaging Platform（UMP）を使用して、地域に応じた広告プライバシーの選択肢を提供します。

## アプリ内課金

本アプリは、買い切り型のアプリ内課金「広告非表示」を提供します。決済および購入履歴はAppleのApp StoreとStoreKitにより処理されます。本アプリは、広告非表示の有効状態を端末内に保存します。

機種変更や再インストール後は、アプリ内の「購入を復元」から購入履歴を確認できます。

## データの保存場所

ユーザーが入力したシフト、勤務、売上データは端末内のローカルデータベースに保存されます。
アプリを削除した場合、端末内のデータも削除される場合があります。

## 第三者提供

本アプリは、ユーザーが入力したシフト、勤務、売上データを第三者へ提供しません。

広告配信に伴う情報は、上記の目的でGoogle Mobile Ads SDKを通じてGoogleおよび広告配信に関わる事業者に送信される場合があります。Googleによる情報の取り扱いについては、[Googleのプライバシーポリシー](https://policies.google.com/privacy?hl=ja)をご確認ください。
